# نماء — مساحتك الشخصية للنمو اليومي

موقع شخصي خاص (بإيميل وكلمة مرور) لمتابعة:

- **العادات اليومية** 🔁 — عادات بأيام محددة، علامة صح يومية، سلسلة الأيام المتتالية 🔥، نسبة الالتزام آخر 30 يوم، وخريطة التزام لآخر 15 أسبوع.
- **الجدول والالتزامات** 🗓️ — مواعيد ومهام بالوقت والتصنيف والأولوية، عرض أسبوعي، تكرار أسبوعي، قائمة المتأخر مع زرار "للنهارده"، وملخص الأسبوع.
- **تطوير المهارات** 🧠 — حوالي 60 سؤال جاهز في 7 مجالات (تفكير منطقي، إنتاجية، تواصل، إنجليزي، ثقافة مالية، برمجة، ثقافة عامة) + أسئلتك انت:
  - **تحدي يومي**: 10 أسئلة متنوعة بتتغير كل يوم.
  - اختبار حسب المجال، اختبار عشوائي، و**مراجعة الأخطاء** (الأسئلة اللي غلطت فيها آخر مرة).
  - شرح بعد كل إجابة، نسبة الدقة لكل مجال، وسجل المحاولات.
- **لوحة رئيسية** فيها ملخص اليوم، **وضع ليلي**، تصميم عربي (RTL) متجاوب مع الموبايل، تغيير كلمة المرور، وتنزيل نسخة احتياطية.

## التقنيات

React 19 + Vite + Tailwind CSS، والـ backend هو **Supabase** (تسجيل دخول + قاعدة بيانات Postgres) — من غير أي سيرفر تديره بنفسك.

كل جدول في قاعدة البيانات محمي بـ **Row Level Security**: كل مستخدم يقدر يقرا ويعدّل صفوفه هو بس، حتى لو حد عرف مفتاح الـ API العام.

## التشغيل محليًا

```bash
npm install
npm run dev
```

من غير إعداد Supabase الموقع بيشتغل في **وضع تجريبي**: الحساب والبيانات بتتحفظ في المتصفح بس (مفيد للتجربة، مش للاستخدام الحقيقي).

## ربط Supabase (عشان الحماية الحقيقية)

1. اعمل حساب مجاني على [supabase.com](https://supabase.com) وأنشئ مشروع جديد.
2. من **SQL Editor** الصق محتوى الملف [`supabase/schema.sql`](supabase/schema.sql) واضغط **Run**.
3. من **Project Settings → API** انسخ `Project URL` و `anon public key`.
4. انسخ `.env.example` باسم `.env.local` وحط القيم دي فيه.
5. شغّل `npm run dev`، وادخل على "أنشئ حسابك" واعمل حسابك.
6. **اقفل التسجيل** بعد ما تعمل حسابك عشان محدش غيرك يعمل حساب:
   - Supabase → **Authentication → Sign In / Providers** → اقفل **Allow new users to sign up**.
   - وخلّي `VITE_ALLOW_SIGNUP=false` عشان الزرار يختفي من صفحة الدخول.

> لو مش عايز تأكيد بالإيميل: Authentication → Sign In / Providers → Email → اقفل **Confirm email**.

## النشر (مجانًا)

الموقع static بالكامل، فينفع على **Vercel** أو **Netlify** أو **Cloudflare Pages**:

- Build command: `npm run build`
- Output directory: `dist`
- ضيف متغيرات البيئة `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` و `VITE_ALLOW_SIGNUP` من إعدادات المشروع هناك.

الروابط بتستخدم `#` (HashRouter) فمش محتاج أي إعدادات إعادة توجيه على الاستضافة.

## بنية المشروع

```
src/
  lib/backend.js       ← طبقة البيانات (Supabase أو الوضع التجريبي)
  lib/habits.js        ← حساب السلاسل ونسب الالتزام
  lib/quiz.js          ← التحدي اليومي، مراجعة الأخطاء، الإحصائيات
  data/questions.js    ← بنك الأسئلة الجاهز (عدّل أو زوّد براحتك)
  pages/               ← الرئيسية، العادات، الجدول، المهارات، الاختبار، أسئلتي، الإعدادات
supabase/schema.sql    ← جداول قاعدة البيانات + صلاحيات الحماية
```
