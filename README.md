# نماء — مساحتك الشخصية للنمو اليومي

موقع شخصي خاص (بإيميل وكلمة مرور) لمتابعة:

- **العادات اليومية** 🔁
  - 3 أنواع: ✅ **أساسية** (بتحسب في نسبتك) · ⭐ **إضافي** (بتعلّي النسبة ومش بتقللها، زي السنن والأذكار) · ✕ **عادة أتجنبها** (بتعلّم ✕ بس في اليوم اللي وقعت فيه).
  - **جدول أسبوعي** (سبت ← جمعة) مقسّم لأقسام، و**تقييم لكل يوم** = (الأساسية اللي اتعملت + أيام التجنب النضيفة + الإضافي) ÷ (الأساسية + التجنب) — ممكن يعدّي 100% ⭐.
  - **حزم جاهزة**: لياقة وصحة، الصلوات الخمس، سنن وأذكار، عادة X.
  - سلاسل الأيام 🔥، نسبة آخر 30 يوم، وخريطة التزام.
- **الجدول والالتزامات** 🗓️ — مواعيد ومهام ومناسبات، عرض أسبوعي، تكرار أسبوعي، المتأخر، وعدّاد تنازلي للمناسبة الجاية.
- **تطوير المهارات** 🧠
  - **مجالاتك بنفسك** ومقسّمة لمواضيع (مثلًا: الإنجليزي ← إنترفيو، جمل، جرامر · ديني ← أحاديث، آيات · تقني ← HTML، CSS).
  - **أنواع أسئلة**: اختيارات، صح/غلط، إجابة مكتوبة قصيرة (تصحيح تلقائي)، كتابة موضوع (مقارنة بإجابة نموذجية + كلمات مطلوبة + تقييم ذاتي)، و**استماع من فيديو يوتيوب** (اسمع واكتب).
  - **تصحيح بيوريك الغلط بالظبط**: الكلمات الناقصة والزيادة متلوّنة، والتصحيح بيتجاهل الحروف الكبيرة والعلامات وبيفهم I’m = I am.
  - 🎤 **جاوب بصوتك** (تحويل الكلام لنص — Chrome/Edge)، 🔊 **اسمع النطق الصح**، و🎙️ **سجّل نطقك** وقارن.
  - تحدي يومي، اختبار عشوائي، اختبار مجال بعدد أسئلة تختاره، و**مراجعة الأخطاء**.
  - **حزم أسئلة**: حزمة "الإنجليزي — تعبيرات وجمل" (~300 سؤال) جوه الموقع، واستيراد/تصدير ملفات JSON لحزمك الخاصة.
- **لوحة رئيسية** على شكل ويدجتس، **وضع ليلي**، تصميم عربي متجاوب، تغيير كلمة المرور، ونسخة احتياطية.

## التقنيات

React 19 + Vite + Tailwind CSS، والـ backend هو **Supabase** (تسجيل دخول + قاعدة بيانات Postgres) — من غير أي سيرفر تديره بنفسك.

كل جدول في قاعدة البيانات محمي بـ **Row Level Security**: كل مستخدم يقدر يقرا ويعدّل صفوفه هو بس، حتى لو حد عرف مفتاح الـ API العام.

## التشغيل محليًا

```bash
npm install
npm run dev
```

من غير إعداد Supabase الموقع بيشتغل في **وضع تجريبي**: الحساب والبيانات بتتحفظ في المتصفح بس (مفيد للتجربة، مش للاستخدام الحقيقي).

## ربط Supabase (عشان الحماية الحقيقية)

1. اعمل حساب مجاني على [supabase.com](https://supabase.com) وأنشئ مشروع جديد.
2. من **SQL Editor** الصق محتوى الملف [`supabase/schema.sql`](supabase/schema.sql) واضغط **Run**. (لو كنت شغلته قبل كده، شغّله تاني بعد أي تحديث — آمن يتشغل أكتر من مرة.)
3. من **Project Settings → API** انسخ `Project URL` و `anon public key`.
4. انسخ `.env.example` باسم `.env.local` وحط القيم دي فيه.
5. شغّل `npm run dev`، وادخل على "أنشئ حسابك" واعمل حسابك.
6. **اقفل التسجيل** بعد ما تعمل حسابك عشان محدش غيرك يعمل حساب:
   - Supabase → **Authentication → Sign In / Providers** → اقفل **Allow new users to sign up**.
   - وخلّي `VITE_ALLOW_SIGNUP=false` عشان الزرار يختفي من صفحة الدخول.

> لو مش عايز تأكيد بالإيميل: Authentication → Sign In / Providers → Email → اقفل **Confirm email**.

## النشر (مجانًا)

الموقع static بالكامل، فينفع على **Vercel** أو **Netlify** أو **Cloudflare Pages**:

- Build command: `npm run build`
- Output directory: `dist`
- ضيف متغيرات البيئة `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` و `VITE_ALLOW_SIGNUP` من إعدادات المشروع هناك.

الروابط بتستخدم `#` (HashRouter) فمش محتاج أي إعدادات إعادة توجيه على الاستضافة.

## بنية المشروع

```
src/
  lib/backend.js       ← طبقة البيانات (Supabase أو الوضع التجريبي)
  lib/habits.js        ← حساب السلاسل ونسب الالتزام
  lib/quiz.js          ← التحدي اليومي، مراجعة الأخطاء، الإحصائيات
  data/questions.js    ← بنك الأسئلة الجاهز (عدّل أو زوّد براحتك)
  pages/               ← الرئيسية، العادات، الجدول، المهارات، الاختبار، أسئلتي، الإعدادات
supabase/schema.sql    ← جداول قاعدة البيانات + صلاحيات الحماية
```

## حزم الأسئلة

ملف الحزمة JSON بالشكل ده:

```json
{
  "name": "اسم الحزمة",
  "categories": [
    { "key": "en", "name": "الإنجليزي", "icon": "🇬🇧", "color": "sky", "parent": null },
    { "key": "grammar", "name": "Grammar", "icon": "📘", "color": "sky", "parent": "en" }
  ],
  "questions": [
    { "category": "grammar", "type": "text", "lang": "en", "text": "اكتب بالإنجليزي: «أنا بحاول أفهم»", "answer_text": "I'm trying to understand.", "accepted": [], "explanation": "trying to + فعل" },
    { "category": "grammar", "type": "mcq", "text": "...", "options": ["a", "b", "c"], "answer": 1 },
    { "category": "en", "type": "writing", "text": "Tell me about yourself.", "answer_text": "إجابة نموذجية...", "keywords": ["background", "experience"] },
    { "category": "en", "type": "listening", "text": "اسمع واكتب", "answer_text": "النص المنطوق", "media": { "youtube": "VIDEO_ID", "start": 65, "end": 75 } }
  ]
}
```

المجالات بتتدمج بالاسم، فممكن تستورد كذا حزمة لنفس المجال.

`scripts/build_english_packs.py` بيحوّل شيت الإنجليزي (Excel) لحزمتين: حزمة عامة جوه الموقع، وحزمة شخصية (مقابلات، عنّي، الكورس) **ماتترفعش مع الكود** — بتستوردها من زرار "حزم جاهزة ← اختار ملف" فتتحفظ في حسابك بس.
